How to walk the sequence

  1. Saved (toggle on) — starting confirmation; Save is muted with a check.
  2. Save changes — turn the Active Traveler toggle off; the primary navy button appears.
  3. Saving — click Save changes; muted button + rotating icon for ~1.5s.
  4. Saved (toggle off) — confirmation returns; toggle stays off. Flip the toggle again to re-dirty and repeat.
