## Design Specificity Verdict

**Genuinely authored, with real execution slips that undercut it.** The system is distinctive on its own terms — no filled buttons, an oxblood accent rationed to one job, a hand-drawn portrait instead of a stock headshot. This is a designer's own taste, not a template with the logo swapped.

But three implementation slips break the very discipline that makes it specific:
- `.hp-hero__tagline { color: #404040; }` (`index.html:95`) is hardcoded, not a token — it doesn't participate in the dark-mode contrast system.
- The nav logo SVG (`index.html:398`) hardcodes `fill="darkred"`, exactly the value `stylesgem.css:41`'s own comment says was replaced by `--color-accent`.
- `class="visually-hidden"` (`index.html:601`) references a class that doesn't exist anywhere in `stylesgem.css` (only `.sr-only` does).

**Deterministic scan** (`impeccable detect --json index.html`, 11 findings): confirmed true positives — the contrast bug above; 7 (actually 8, one likely undercounted by the detector) instances of `.hp-skill` tags rendering at 9.92px, below the 11px legibility floor and off the documented `--size-label` token; a `2px` border-radius on the hamburger bar outside the documented 3px/4px scale (advisory, low materiality); Lato flagged as an overused font (confirmed a true positive against the detector's actual blocklist, despite its human-readable description text not naming Lato explicitly — corrects an earlier "false positive" call from the standalone audit pass). One false positive: "cramped padding" on `.hp-hero` — the section already has `clamp(3rem, 8vh, 5rem)` vertical padding plus flex-centering; the detector's shorthand-padding parsing appears to have missed it.

## Priority Issues

**[P0] Hero tagline is nearly invisible in dark mode.**
- **Why it matters:** This is the highest-stakes sentence on the page — the one explaining what Matthew does, in the first 5 seconds — and it drops to ~1.7:1 contrast (need 4.5:1) for any visitor on system dark mode, silently opting out of a contrast system the rest of the page carefully implements.
- **Fix:** Replace `color: #404040;` with `color: var(--color-gray);` in `index.html:95`.
- **Suggested command:** `/impeccable harden`

**[P0] "About" heading isn't actually hidden — broken class reference.**
- **Why it matters:** `class="visually-hidden"` (`index.html:601`) doesn't exist in the stylesheet the page loads; only `.sr-only` does. The About section renders an unintended visible "ABOUT" heading where the design intended silence, and the intended screen-reader landmark never fires as designed.
- **Fix:** Change the class to `sr-only`.
- **Suggested command:** `/impeccable harden`

**[P1] Nav logo hardcodes `fill="darkred"`, contradicting the token system and the One Voice Rule — sitewide.**
- **Why it matters:** `--color-accent` was created specifically to retire this value (per its own code comment), but the logo mark that ships on every page of the site — confirmed across BeyondClicks.html, appMerg.html, articles.html, backstory.html, and more — still uses the un-retired hardcoded color, and never adopts the dark-mode-tuned accent.
- **Fix:** Swap `fill="darkred"` for `fill="var(--color-accent)"` (or `currentColor` + CSS `color`) sitewide, in the shared nav block.
- **Suggested command:** `/impeccable harden`

**[P1] Meta description and hero tagline undersell the documented positioning.**
- **Why it matters:** `index.html:15`'s meta description leads with "cultural institutions" as the specialization, but PRODUCT.md is explicit that this is one vertical among several, not the headline — and this is the text that shows up in every search result and link preview a recruiter sees before the page even loads.
- **Fix:** Rewrite the meta description (and tighten the hero tagline) to lead with the cross-domain AI/design-systems throughline PRODUCT.md identifies as current.
- **Suggested command:** `/impeccable clarify`

**[P2] Skill tags are both undersized and cognitively overloaded.**
- **Why it matters:** `.hp-skill` renders at 9.92px (below the 11px legibility floor, smaller than the system's own label token) *and* presents 8 tags in one flat, ungrouped group — past the Working Memory Rule's "8+ = overloaded" threshold for a list meant to be scanned for keyword matches.
- **Fix:** Switch to `var(--size-label)` and split into 2-3 labeled sub-groups (e.g., "Current focus": AI Systems, Design Systems, Figma) — also reinforces the AI/systems specialty from PRODUCT.md.
- **Suggested command:** `/impeccable typeset` then `/impeccable clarify`
